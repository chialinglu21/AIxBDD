# SOP

## Phase 1 — 收斂樣板結構

1. READ 目標 skill 的 SKILL.md 與相關檔案，找出哪一步會 READ 這份樣板、該步要產出什麼檔案。
2. THINK 從使用者口述與上一步讀到的檔案，分出產出檔案中固定不變與每次會變的部分，記下每個部分的出處。
   - 若口述與檔案內容衝突 → 以口述為準。
3. READ `rules/佔位符判準.md`。
4. THINK 依佔位符判準，定出骨架裡的佔位符。
5. READ `rules/樣板命名規範.md`。
6. THINK 依樣板命名規範，定出骨架與範例的路徑。不必詢問使用者。

**產出**：骨架與範例的路徑，以及標好佔位符與出處的樣板結構。

## Phase 2 — 寫出骨架與範例

1. READ `rules/樣板格式規範.md`，這是樣板唯一的格式規範，不參照其他文件的格式。
2. WRITE 依樣板格式規範，將樣板結構寫成骨架，存入 Phase 1 定出的骨架路徑。
3. WRITE 依樣板格式規範，把骨架的佔位符填入具體內容，存入 Phase 1 定出的範例路徑。

**產出**：骨架與範例草稿。

## Phase 3 — 驗收並交付

1. CHECK 逐條對照佔位符判準與樣板格式規範，不合就退回 Phase 2 步驟 2 修改。
2. REPORT 交出骨架與範例，列出每個佔位符、對應的範例內容與出處，請使用者確認。

**產出**：骨架與範例，以及使用者對佔位符與出處的確認。
