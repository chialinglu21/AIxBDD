# Rule 1 - 骨架與範例放在目標 skill 的 templates/ 底下

- 強度：必須
- 骨架與範例的路徑固定在 `<目標 skill>/templates/` 底下。
- 不放在本 skill、其他 skill 或 repo 的其他目錄，否則目標 SOP 用 `templates/<檔名>` READ 時會找不到檔案。

## Good Example

- 為 `plan-with-class-diagram` 寫的樣板放在該 skill 自己的 `templates/` 底下，SOP 的 `READ templates/class-diagram.md` 可以直接讀到。

```markdown
.claude/skills/plan-with-class-diagram/templates/class-diagram.md
.claude/skills/plan-with-class-diagram/templates/class-diagram.example.md
```

## Bad Example

- 同樣兩份檔案被放在執行撰寫的 `skill-form-template/templates/` 底下，`plan-with-class-diagram` 的 SOP 照 `templates/class-diagram.md` 去讀時找不到檔案。

```markdown
.claude/skills/skill-form-template/templates/class-diagram.md
.claude/skills/skill-form-template/templates/class-diagram.example.md
```

# Rule 2 - 副檔名與目標步驟的產出檔一致

- 強度：必須
- 副檔名照目標步驟產出檔的副檔名，不照檔案內容所用的語法。
- 產出檔是包著 mermaid 的 `.md`，樣板就用 `.md`，不用 `.mmd`。

## Good Example

- 目標步驟存成 `docs/design/<功能名稱>-class-diagram.md`，樣板也用 `.md`，骨架裡含標題與 mermaid code block，複製後就是產出檔的雛形。

```markdown
templates/class-diagram.md
templates/class-diagram.example.md
```

## Bad Example

- 同一個產出檔，樣板因為內容是 mermaid 而用了 `.mmd`。骨架裡只有圖、沒有標題與 code block 包裝，複製後存成 `.md` 渲染不出圖。

```markdown
templates/class-diagram.mmd
templates/class-diagram.example.mmd
```

# Rule 3 - 樣板名用英文 kebab-case 寫出產出檔是什麼

- 強度：建議
- 樣板名用小寫英文、以 `-` 連接，寫出產出檔是什麼，例如 `class-diagram`、`api-spec`。
- 不用 Phase、步驟編號命名，因為之後插入 READ 會讓編號推移，檔名就對不上。

## Good Example

- 為 Phase 2 步驟 2 寫的樣板叫 `class-diagram`，步驟編號變動後檔名依然正確。

```markdown
templates/class-diagram.md
```

## Bad Example

- 同一份樣板依當時的位置命名為 `phase2-step2`。插入 READ 之後被把關的 WRITE 變成步驟 3，檔名指向的步驟 2 已經是 READ 本身。

```markdown
templates/phase2-step2.md
```

# Rule 4 - 範例檔名在副檔名前加 `.example`

- 強度：必須
- 範例檔名固定為 `<樣板名>.example.<副檔名>`，與骨架放在同一個目錄。
- 不寫成 `-example`、`_sample`，也不放進 `examples/` 子目錄。

## Good Example

- 骨架與範例只差 `.example`，並排放在一起，依 `<樣板名>.example.<副檔名>` 就找得到範例。

```markdown
templates/
├── class-diagram.md
└── class-diagram.example.md
```

## Bad Example

- 同一份範例改叫 `class-diagram-example.md`，或放進 `examples/` 子目錄，依 `<樣板名>.example.<副檔名>` 去 READ 時找不到檔案。

```markdown
templates/
├── class-diagram.md
├── class-diagram-example.md
└── examples/
    └── class-diagram.md
```
