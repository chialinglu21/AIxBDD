# Rule 1 - 只有每次會變的部分才做成佔位符

- 強度：必須
- 每次產出都相同的標題、段落名稱、語法關鍵字，照原文寫進骨架。
- 只有每次產出都會不同的值，才換成佔位符。

## Good Example

- 標題的功能名稱每次不同，做成佔位符；`類別圖`、`## 類別職責`、`classDiagram` 每次都一樣，照原文寫。

````markdown
# {{功能名稱}} 類別圖

```mermaid
classDiagram
  class {{類別名稱 1}}
  class {{類別名稱 2}}
  %% 依此類推
```

## 類別職責
````

## Bad Example

- 同一份骨架把固定的段落名稱與語法關鍵字也做成佔位符，每次產出的段落名稱都不同，後續步驟要找「類別職責」段落時找不到；`classDiagram` 被換掉後 mermaid 也渲染不出來。

````markdown
# {{標題}}

```mermaid
{{圖表類型}}
  class {{類別名稱 1}}
  class {{類別名稱 2}}
  %% 依此類推
```

## {{段落名稱}}
````

# Rule 2 - 佔位符一律寫成 `{{繁中說明}}`

- 強度：必須
- 佔位符用兩層大括號包住繁中說明，寫成 `{{類別名稱}}`。
- 不用 `<xxx>`、`[xxx]`、`$XXX`；`<xxx>` 會和 mermaid 的 `<<interface>>`、泛型、HTML 標籤撞在一起，分不出哪個要換。

## Good Example

- 佔位符與 `<<interface>>` 的符號不同，填寫時只會換掉 `{{…}}`。

```mermaid
classDiagram
  class {{介面名稱}} {
    <<interface>>
  }
```

## Bad Example

- 同一份骨架用角括號當佔位符，`<介面名稱>` 和 `<<interface>>` 都是角括號，填寫時可能連 `<<interface>>` 也一起換掉。

```mermaid
classDiagram
  class <介面名稱> {
    <<interface>>
  }
```

# Rule 3 - 佔位符的說明寫出要填什麼

- 強度：必須
- 大括號裡用繁中名詞短語寫出要填的內容，例如 `{{類別名稱 1}}`、`{{類別 1 職責}}`。
- 不用 `{{A}}`、`{{x1}}`、`{{內容}}` 這類看不出要填什麼的代號。

## Good Example

- 只看佔位符就知道冒號前填類別名稱、冒號後填這個類別的職責。

```markdown
- `{{類別名稱 1}}`：{{類別 1 職責}}
```

## Bad Example

- 同一行改用代號，看不出 `A`、`B` 各要填什麼，可能把職責填到名稱的位置。

```markdown
- `{{A}}`：{{B}}
```

# Rule 4 - 同一個值在骨架裡用同一個佔位符名稱

- 強度：必須
- 指同一個值的位置，佔位符名稱完全相同；指不同值的位置，名稱不能相同。
- 重複區塊的各組用編號區分，例如 `{{類別名稱 1}}`、`{{類別名稱 2}}`。

## Good Example

- 類別圖與職責清單用同一個 `{{類別名稱 1}}`，填寫後兩處的名稱一定一致。

````markdown
```mermaid
classDiagram
  class {{類別名稱 1}}
  class {{類別名稱 2}}
  %% 依此類推
```

## 類別職責

- `{{類別名稱 1}}`：{{類別 1 職責}}
- `{{類別名稱 2}}`：{{類別 2 職責}}
<!-- 依此類推 -->
````

## Bad Example

- 同一份骨架裡，兩個類別用同一個名稱，分不出是不是同一個；職責清單又換成 `{{類別}}`，看不出要對應圖上哪個類別，可能填出圖上不存在的類別。

````markdown
```mermaid
classDiagram
  class {{類別名稱}}
  class {{類別名稱}}
  %% 依此類推
```

## 類別職責

- `{{類別}}`：{{職責}}
- `{{類別}}`：{{職責}}
<!-- 依此類推 -->
````

# Rule 5 - 重複區塊寫兩組示意並加「依此類推」註解

- 強度：必須
- 產出時會出現 1..n 次的區塊，骨架裡寫兩組，第二組之後加一行「依此類推」註解。
- 註解用產出格式自己的註解語法：markdown 用 `<!-- 依此類推 -->`，mermaid 用 `%% 依此類推`。

## Good Example

- 兩組示意加上註解，看得出這裡要依實際的類別數展開。

```markdown
## 類別職責

- `{{類別名稱 1}}`：{{類別 1 職責}}
- `{{類別名稱 2}}`：{{類別 2 職責}}
<!-- 依此類推 -->
```

## Bad Example

- 同一個區塊只寫一組、沒有註解，看起來就只有一個類別，照抄後職責清單只列出一個類別。

```markdown
## 類別職責

- `{{類別名稱}}`：{{類別職責}}
```
