# SOP

## Phase 1 — 定出邊界

1. READ 目標 skill 的 frontmatter，抓出觸發條件與任務範圍。
2. THINK 推出「輸入 → 產出」一句話：做完之後使用者手上多了什麼。
3. ASK 輸入來源、產出位置、誰拍板，有任一不明確就一次問清楚，不要邊寫邊猜。

**產出**：一句話的任務邊界。

## Phase 2 — 寫出 SOP

1. READ `rules/sop-格式規範.md` 與 `rules/sop-撰寫原則.md`。
2. THINK 從產出回推里程碑，一個里程碑一個 Phase。
3. WRITE 依格式規範與撰寫原則，寫出 Phase 標題、產出行與步驟。

**產出**：SOP 草稿。

## Phase 3 — 驗收並交付

1. CHECK 逐條對照格式規範、動詞判準與撰寫原則，不合就改；改不動就退回 Phase 2 重切。
2. REPORT 交出 SOP，點名哪幾步是 ASK 關卡，請使用者確認關卡位置。

**產出**：可執行的 SOP，以及使用者對關卡位置的確認。
